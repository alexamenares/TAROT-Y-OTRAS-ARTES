Nosotros

Un proyecto académico con mirada espiritual

Tarot y Otras Artes organiza experiencias, recursos y contenidos simulados para aprender frontend sin depender todavía del backend.

Propósito

Acompañar el aprendizaje y la reflexión

Este MVP transforma el concepto de tienda en una selección de experiencias espirituales, publicaciones y recursos de biblioteca. Todo funciona con HTML, CSS, Bootstrap y JavaScript puro.

  • Datos simulados, sin conexión a API por ahora.
  • Validaciones visibles y mensajes personalizados.
  • Navegación pública y administración simulada.
