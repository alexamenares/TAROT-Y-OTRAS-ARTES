# Tarot y Otras Artes — Versión 2.0

Frontend estático del MVP con rediseño **Material 3 — Ritual nocturno**.

## Abrir el proyecto

1. Abrir esta carpeta en Visual Studio Code.
2. Instalar o usar la extensión Live Server.
3. Abrir `index.html` con Live Server.

No requiere `npm install`, compilación ni backend. Bootstrap 5.3.8 y las fuentes Cinzel/Lora se cargan desde CDN; el CSS, JavaScript, ouróboro y cartas son locales.

## Documentación

- `INFORME_IMPLEMENTACION_VERSION_2_0.md`: alcance, decisiones y verificación.
- `PLAN_PRUEBAS_MANUALES_VERSION_2_0.md`: casos y datos para la defensa.
- `ESPECIFICACION_REDISENO_MATERIAL3_RITUAL_NOCTURNO.md`: especificación de referencia, cuando se conserve junto al proyecto.

## Estructura principal

- `index.html`: portada inmersiva, experiencias destacadas y acceso administrativo inferior.
- `experiencias.html` y `detalle-experiencia.html`: catálogo y detalle.
- `mi-seleccion.html`: persistencia local y eliminación confirmada.
- `biblioteca.html`: seis recursos filtrables.
- `blog.html` y dos detalles editoriales.
- `nosotros.html`: propósito y video.
- `contacto.html`, `registro.html`, `login.html`: formularios simulados.
- `admin.html`: panel interno simulado.
- `css/estilos.css`: sistema visual completo.
- `js/interfaz.js`: componentes de feedback reutilizables.
- `imagenes/portada-ritual-nocturno-v2.png`: escena panorámica original utilizada en Inicio.
